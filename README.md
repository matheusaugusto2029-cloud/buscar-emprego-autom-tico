# Buscar Emprego Automático

### Sobre o Projeto
Este é um sistema simples de automação desenvolvido para pesquisar vagas de emprego de forma automática. O programa realiza buscas automáticas em sites de emprego, otimizando o tempo e facilitando a busca por oportunidades na área desejada.

* **Linguagem usada:** Python
* **Biblioteca utilizada:** PyAutoGUI

O sistema utiliza o controle do teclado e mouse automaticamente de acordo com o que foi programado, com um sistema de pausa, para que o programa não execute muito rápido.

### Funcionalidades
* Facilita a busca de empregos sem a necessidade de abrir manualmente o navegador.
* Realiza pesquisas repetitivas de forma automatizada.
* **Pronto para uso:** É só abrir o código, executar e o programa já vai pesquisar automaticamente. 

> 💡 **Nota:** Eu selecionei para que você buscasse na área de Python, mas você pode colocar para ele pesquisar o que você quiser modificando o código fonte. É uma ótima economia de tempo para quem está buscando emprego e não quer esperar o navegador abrir, pesquisando e talvez não encontrar a vaga que viu no dia anterior.
