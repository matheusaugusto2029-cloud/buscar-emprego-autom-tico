Projeto: Automação de Busca de Empregos
Descrição:
Sistema simples de automação desenvolvido para pesquisar vagas de emprego de forma automática. O programa realiza buscas automáticas em sites de emprego, otimizando o tempo e facilitando a procura por oportunidades na área desejada.
Linguagem usada: Python
Bilioteca utilizada: Pyautogui
O sistema utiliza o controle do teclado e mouse automaticamente de acordo com o que foi programado, com um sistema de pause, para que o programa não execute muito rapido.
Funcionalidades:
Facilitar a busca de empregos sem a necessidade de abrir manualmente o navegador e realizar pesquisas repetitivas. é só abrir o codigo executar e o programa já vai pesquisar automaticamente. eu selecionei para que buscasse na área de python, mas você pode colocar para ele pesquisar o que  você quiser  modificando o código fonte.
Economia de tempo para quem esta buscando emprego e não quer esperar o navegador abrir, pesquisar e talvez não encontar a vaga que ele viu no dia anterior.
